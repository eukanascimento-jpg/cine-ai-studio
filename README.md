# CINE AI Studio Offline
Protótipo Android para gerar animações procedurais locais em MP4. Sem modelos generativos 3D, sem vozes e sem serviço online. Código experimental, ainda não testado no Moto G75.

O GitHub Actions compila o APK em Actions > Compilar APK. Baixe o artefato CINE-AI-Studio-APK.


Build automático: workflow GitHub Actions em cada push. APK experimental, sem geração de vídeo por IA generativa. Um milhão de linhas não melhora a qualidade ou substitui modelos e GPUs.
